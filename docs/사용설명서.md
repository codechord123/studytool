# 임선생의 도형학습 — 선생님용 사용 설명서

초등 5·6학년 **도형(둘레·넓이·각도·입체)** 수업을 위한 인터랙티브 학습 도구입니다.
아이들이 직접 도형을 그리고, 자르고, 붙이고, 돌리며 **넓이·둘레 공식을 스스로 발견**하도록 돕고,
입체도형은 **전개도·단면·쌓기나무**로 3차원 감각을 길러 줍니다.

> 이 문서 하나로 수업 준비가 끝나도록 만들었습니다. 급하실 때는 **‘5분 빠른 시작’**과 **‘차시별 수업 예시’**만 보셔도 됩니다.

## 1. 5분 빠른 시작

1. **접속** — 태블릿·PC의 웹 브라우저(크롬 권장)로 앱 주소에 들어갑니다. 설치가 필요 없습니다.
2. **도형 부르기** — 화면 상단의 **📐 도형 추가**를 눌러 직사각형·삼각형·사다리꼴 등 기본 도형을 불러옵니다.
3. **만져 보기** — 도형을 손가락(또는 마우스)으로 **끌어 이동**, 두 손가락으로 **확대/축소**할 수 있습니다.
4. **공식 발견하기** — 상단 **📚 학습 예시**를 누르면 “사다리꼴 → 평행사변형 만들기”처럼 **단계별 활동**이 자동으로 준비됩니다.
5. **설명 쓰고 제출** — **📝 글상자** 도구로 “어떻게 바꿨는지” 설명을 적고, **📷 저장·제출**을 누르고 이름을 적으면 그림과 설명이 **한 장의 이미지**로 저장됩니다. 이 이미지를 제출·게시하면 됩니다.
6. **입체 수업** — 상단 **🧊 입체도형** 버튼으로 3D 학습 화면으로 이동합니다.

> 💡 **되돌리기**는 언제든 상단의 **↩︎ / ↪︎** 버튼(또는 `Ctrl+Z` / `Ctrl+Shift+Z`)으로 가능합니다. 실수를 두려워하지 않고 마음껏 실험하게 해 주세요.

## 2. 화면 구성 한눈에 보기

| 위치 | 내용 |
|------|------|
| **상단 바(왼쪽)** | 앱 이름 · **📐 도형 추가** · **📚 학습 예시** · **🧊 입체도형**(3D 이동) |
| **상단 바(가운데)** | **격자**(1 / 0.5 / 0.2 / 끄기) · **🧲 자석** · **넓이** · **칸세기** · **각도** · **변길이** · **글자 가− / 가+** |
| **상단 바(오른쪽)** | **↩︎ ↪︎ 되돌리기** · **📽️ 전자칠판** · **📷 저장·제출** · **전체 초기화** |
| **왼쪽 세로 도구막대** | 8가지 도구(선택·그리기·자르기·합치기·길이재기·가이드·글상자·삭제) |
| **오른쪽 정보 카드** | 선택한 도형의 **넓이·둘레**, 여러 개 선택 시 **합계**, 각도 켜면 **내각의 합** |
| **아래(왼쪽)** | 확대/축소(**− % +**)와 **맞춤**(화면에 딱 맞게) |

> 📌 정보 카드나 도구막대가 화면을 가리면 **패널 위쪽의 손잡이(⣿)를 잡아 원하는 위치로 옮길 수 있습니다.** 태블릿 화면 비율이 달라도 자유롭게 배치하세요. 각 패널은 **접기(▾) / 펴기(▸)** 버튼으로 최소화할 수 있어요(스마트폰에서 특히 유용):
> - 왼쪽 **도구막대** → 상단 **◀ 접기 / 🧰 펴기**
> - 오른쪽 위 **넓이·둘레 카드** → 오른쪽 위 **▾**, 접히면 **📊 넓이·둘레 ▸** 알약으로 축소
> - 아래 **색상·회전 도구모음(선택 시)** → 왼쪽 **▾**, 접히면 **🎨 도형 도구 ▸** 알약으로 축소
> 접힘 상태는 **브라우저에 기억**되어 다음 접속 때도 유지됩니다.

## 3. 평면 도형 학습 (2D)

### 3-1. 도형 불러오기 — 📐 도형 추가
버튼을 누르면 기본 도형 목록이 나옵니다. 각 도형에는 **넓이 공식**이 함께 적혀 있습니다.

- 사각형류: **정사각형, 직사각형, 평행사변형, 사다리꼴, 마름모**
- 삼각형류: **직각삼각형, 삼각형, 정삼각형**
- 정다각형: **정오각형, 정육각형, 정팔각형, 정십각형, 정십이각형**
- 합성도형: **ㄴ자 모양, 십자 모양**(여러 직사각형의 합으로 넓이 구하기)
- **⭕ 원** — 선택하면 **반지름 선과 값**이 표시되고, **테두리를 잡아 끌면 반지름이 정수 cm 단위로** 조절됩니다. 정보 카드에 **넓이(=πr²)·원주(=2πr)**가 함께 표시되어, 반지름을 바꿔가며 원주·넓이 변화를 관찰하는 활동에 좋습니다. (칸세기를 켜면 원의 넓이를 칸으로 어림하는 활동도 가능)

### 3-2. 도구 8가지 (왼쪽 세로 막대)

| 아이콘 | 도구 | 하는 일 | 단축키 |
|:---:|------|---------|:---:|
| 🖱️ | **선택·이동** | 도형을 눌러 선택하고 끌어서 이동. **Ctrl/Shift+클릭**으로 여러 개 선택, **변 가운데 ➕**로 꼭짓점 추가, **꼭짓점 옆 빨간 ➖ 배지를 탭**하면 꼭짓점 삭제, 위쪽 **초록 손잡이로 회전**(아래 3-2-1 참고) | `A` |
| ✏️ | **그리기** | 빈 곳을 눌러 꼭짓점을 찍어 원하는 다각형을 직접 그림. 첫 점을 다시 누르거나 `Enter`로 완성 | `S` |
| ✂️ | **자르기** | 도형 위를 드래그해 **가로·세로·대각선**으로 자름 | `D` |
| 🔗 | **합치기** | 두 도형을 차례로 눌러 하나로 합침. **또는 여러 도형을 Ctrl/Shift+클릭으로 선택한 뒤 합치기(또는 `F`)를 누르면 한꺼번에 합쳐짐.** 한 변이 맞붙어야 함(자석 켜면 쉬움) | `F` |
| 📏 | **길이재기** | 두 점을 드래그해 길이를 잼. 끝점·선을 잡아 옮기고 `Delete`로 지움 | `Q` |
| 📐 | **가이드** | 점선 보조선을 그어 “여기서 자를까?”를 미리 표시 | `W` |
| 📝 | **글상자** | 빈 곳을 눌러 설명 글상자를 만들고 글을 씀(아래 3-5 참고) | `T` |
| 🗑️ | **삭제** | 지우고 싶은 도형이나 글상자를 누름 | `E` |

> 각 도구를 고르면 화면 아래에 **사용법 안내 문구**가 자동으로 나타납니다.

#### 3-2-1. 각도 맞추기 (회전)
선택한 도형 위의 **초록 손잡이**를 잡고 돌리면 **15° 단위로만** 회전합니다 (0°·15°·30°…·90°·180°).

- 돌리는 동안 **현재 돌린 각도 배지**가 표시됩니다.
- 항상 15°의 배수로만 돌아가므로 **180° 돌리면 정확히 반대**, 같은 만큼 되돌리면 **처음 위치로 정확히 복귀**합니다. 어중간한 각도로 남는 일이 없습니다.
- **🎓 학습모드**에서는 90° 단위로만 돌아가 격자를 벗어나지 않습니다.
- **임의의 각도**로 자유롭게 돌리려면 **`Shift`를 누른 채** 돌리세요.
- 아래 도구모음의 **↶90° / ↷90° / 180°** 버튼으로도 정확히 돌릴 수 있습니다.

> 💡 “삼각형을 180° 돌려 붙이기”, “직각삼각형을 90° 회전” 같은 넓이 활동에서 각도가 어긋나지 않아 도형이 깔끔하게 맞붙습니다.

#### 3-2-2. 꼭짓점 옮길 때 각도·변 자동 맞춤
꼭짓점을 끌어 도형을 변형할 때, **내각이 15°·30°·45°·60°·90°처럼 자주 쓰는 각도에 자동으로 딱 맞춰지고, 변 길이도 정수(cm)에 딱 떨어지게** 붙습니다. 예를 들어 정삼각형의 한 꼭짓점을 당기면 30°–60°–90° 직각삼각형으로 반듯하게 잡힙니다.
- 자석을 잠시 끄고 **완전히 자유롭게** 옮기고 싶으면 **`Shift`를 누른 채** 드래그하세요.

#### 3-2-3. 🔷 반듯하게 (정다각형으로 맞추기)
정삼각형·정오각형·정육각형처럼 **변이 거의 같은 도형**을 선택하면 아래 도구모음에 **🔷 반듯하게** 버튼이 나타납니다. 누르면 **변 길이와 내각이 딱 떨어지는 완벽한 정다각형**으로 한 번에 정돈됩니다. (손으로 그리거나 살짝 틀어진 정다각형을 “약 5cm” 같은 어림값 없이 반듯하게 만들 때 사용하세요.)

> 📎 **참고:** 정다각형의 *넓이*(예: 정삼각형)는 수학적으로 딱 떨어지지 않아 **약 …cm²**로 표시됩니다. 이때 정보 카드의 **🎯 넓이 딱 맞추기** 버튼을 누르면 꼭짓점을 격자에 맞추고 **넓이가 정수가 되도록** 모양을 살짝 보정해 줍니다. 상단 **🎯 딱맞춤** 토글을 켜 두면 등변·등각을 만들 때 자동으로 적용됩니다.

#### 3-2-4. 🪞 선대칭 · 🔃 점대칭 그리기 (5-2 «합동과 대칭» 대응)
**✏️ 그리기** 도구를 고르면 화면 아래에 **일반 / 🪞 선대칭 / 🔃 점대칭** 선택이 나타납니다.

- **🪞 선대칭 그리기** — 세로 **대칭축**(분홍 점선)이 나타나고, 축의 한쪽에 점을 찍으면 **반대쪽에 거울상이 실시간으로** 따라 그려집니다.
  - **시작 점과 끝 점을 축 위에** 찍으면 → 하나의 **선대칭도형**이 완성됩니다. ("축을 따라 접으면 완전히 겹쳐요")
  - 축에서 떨어진 채 완성하면 → **서로 합동인 두 도형**(원본+거울상)이 만들어집니다. (2~3차시 합동 학습에 활용)
  - 축은 위쪽 **동그라미 손잡이**를 잡아 좌우로 옮길 수 있습니다.
- **🔃 점대칭 그리기** — **대칭의 중심**(보라 ✚)이 나타나고, 중심의 한쪽에 그리면 **180° 돌린 반대쪽이 실시간으로** 완성됩니다.
  - **끝 점을 시작 점의 정반대편**(중심 대칭 위치)에 찍으면 → 하나의 **점대칭도형**이 완성됩니다.
  - 아니면 → 서로 합동인 두 도형(원본+180° 회전상)이 만들어집니다.
- **대칭 판별** — 상단 **🪞 대칭** 토글을 켜고 도형을 선택하면, *어떤 도형이든* (직접 그린 것 포함) 실제로 검사해 **대칭축(분홍 점선)**과 **대칭의 중심(보라 ✚)**을 그려 주고, 정보 카드에 **"선대칭 ○·축 n개 / 점대칭 ○·✗"** 판별 결과가 표시됩니다. (4~9차시 성질 탐구·판별 활동)

### 3-3. 표시 옵션 (상단 가운데)

- **격자** — 모눈 간격을 **1 / 0.5 / 0.1 / 끄기**로 바꿔 정밀도를 조절합니다. 켜져 있으면 **도형을 이동·크기 조절(×½/×2)할 때 왼쪽·위 모서리가 격자에 딱딱** 붙습니다. **`Shift`를 누른 채**로 하면 격자와 무관하게 자유롭게 움직입니다. (0.1로 두면 아주 세밀하게 움직일 수 있어요.)
- **🧲 자석** — 켜면 도형이 격자와 다른 도형의 변에 **딱 달라붙어** 정확히 이어 붙일 수 있습니다. *합치기 활동에는 켜 두는 것을 권장합니다.*
- **🔒 자연수** — 켜면 **모든 꼭짓점이 모눈 교차점(정수 cm)에만** 놓이도록 강제합니다. 격자는 자동으로 1cm, 회전은 90° 단위, 이동·꼭짓점 편집 후 좌표가 정수로 반올림됩니다. **자연수만으로 넓이·둘레를 다루는 저학년 학습에 유용**합니다.
- **🎯 딱맞춤** — 넓이가 소수로 나오는 도형을 **①꼭짓점을 격자 교차점에 ②넓이가 정수가 되도록** 자동 보정합니다. 등변·등각 버튼과 함께 쓰면 편리합니다.
- **🎓 학습모드** — *정해진(깔끔한) 값만으로 학습*하도록 안내하는 모드입니다. 켜면 자연수·딱맞춤이 항상 켜지고, 회전은 90°씩, 도형을 만들거나 꼭짓점을 놓으면 **변 길이·넓이가 딱 떨어지는 모양**(예: 16·17·17 삼각형)으로 자동으로 맞춰집니다. 끄면 자유모드입니다.
- **⬜ 무격자** — 모눈을 숨깁니다. 칸을 셀 수 없으니 **공식과 표시된 길이만으로** 넓이를 구하는 연습이 됩니다. (칸세기 → 격자 → 무격자 순의 학습 단계로 활용하세요.)
- **넓이** — 도형 안에 넓이(cm²)를 표시합니다.
- **칸세기** — 도형이 덮은 모눈 칸을 **꽉 찬 칸 / 걸친 칸**으로 색칠해 어림 넓이를 셀 수 있게 합니다. (넓이 개념 도입에 유용)
- **🪞 대칭** — 선택한 도형의 **대칭축·대칭의 중심**을 실제 검사로 찾아 표시하고, 정보 카드에 선대칭/점대칭 판별 결과를 보여 줍니다.
- **각도** — 각 꼭짓점의 **내각**과 **내각의 합**을 보여 주고, `(변의 수 − 2) × 180°` 공식을 유도합니다.
- **변길이** — 각 변의 길이(cm)를 켜고 끕니다.
- **글자 가− / 가+** — 화면에 표시되는 숫자·라벨 크기를 4단계로 키웁니다. **전자칠판·큰 화면 수업에 유용합니다.**

### 3-4. 학습 예시 — 📚 (넓이 공식 발견 활동)
버튼을 누르면 교과 흐름에 맞춘 **단계별 활동**이 준비됩니다.

- 🔷 **사다리꼴의 넓이** — 같은 사다리꼴 두 개로 평행사변형 만들기 / 가운데를 잘라 직사각형 만들기 / 대각선으로 잘라 삼각형 두 개로 나누기
- 🔶 **평행사변형의 넓이** — 끝을 잘라 옮겨 직사각형 만들기 / 대각선으로 잘라 합동 삼각형 만들기
- 🔺 **삼각형의 넓이** — 직각삼각형 두 개 → 직사각형 / 일반 삼각형 두 개 → 평행사변형
- 💎 **마름모의 넓이** — 두 대각선으로 4개의 직각삼각형 / 마름모를 둘러싼 직사각형의 절반
- ▭ **직사각형의 넓이** — 모눈 칸 세기 / 대각선으로 잘라 직각삼각형 두 개

각 활동은 조작 후 **“그래서 넓이 공식은 …”** 하는 정리 문구와 간단한 **확인 문제**로 마무리됩니다. 아이들이 “외우는” 게 아니라 **직접 만들어 알아내도록** 설계했습니다.

> 💡 활동 중 위쪽 **설명 패널**은 **▲ 접기**로 잠시 접어 도형을 크게 볼 수 있고(제목 알약을 누르면 다시 펼침), **그만두기 ✕**는 실수 방지를 위해 **확인 후에만** 종료됩니다.

#### 🎮 문제 풀이 모드 (시험 보기)
학습 예시 서랍 맨 위의 **▶ 문제 풀기 시작**을 누르면 시험 모드가 열립니다.

- **문항 수**(10/20/30) · **난이도**(쉬움/보통/어려움) · **유형**(직사각형·평행사변형·삼각형·사다리꼴·합성 도형)을 골라 시작합니다.
- 문제 도형은 **직접 자르고 칸을 세며** 탐구할 수 있고, **↺ 도형 되돌리기**로 처음 상태로 복원됩니다.
- 오답이 3회 누적되면 **푸는 방법 힌트**가 제공됩니다. 채점 결과는 진행 칩으로 한눈에 보입니다.
- 완주하면 점수와 **틀린 문제 다시 풀기**가 제공되고, 최고 기록(%)이 저장됩니다.

### 3-5. 글상자와 제출 — 📝 + 📷 저장·제출
아이들이 **도형을 어떻게 변형했는지 설명을 쓰고, 그림과 함께 한 번에 제출**할 수 있습니다.

1. **📝 글상자** 도구를 고른 뒤 빈 곳을 누르면 노란 메모 상자가 생깁니다.
2. 설명을 입력합니다. **여러 줄**을 쓸 수 있고, 글쓰는 동안에는 도구 단축키가 끼어들지 않습니다.
3. 다른 도구를 누르거나 바깥을 클릭하면 메모가 **캔버스 위에 고정**됩니다.
4. 글상자는 **프레젠테이션처럼** 다룹니다 — **몸통을 끌면 이동**, **한 번 탭하면 선택**, **선택된 상자를 다시 탭하면 글 수정**, **오른쪽 아래 모서리 손잡이**를 끌면 **크기(글자 포함) 조절**. 선택 도구·글상자 도구 어디서든 똑같이 동작하고, `Shift`를 누른 채면 격자와 무관하게 자유롭게 움직입니다.
5. **📷 저장·제출**을 누르면 **제출 창**이 열립니다. **이름**(과 선택적으로 제목·메모)을 적고 **💾 저장하기**를 누르면, 위쪽에 **이름·날짜**가 찍힌 **제출용 PNG 이미지 한 장**으로 저장됩니다. 도형·눈금·설명 글상자가 모두 함께 담깁니다.
   - 입력한 **이름은 다음 저장 때 자동으로 기억**됩니다.
   - 저장 직전까지 쓰던 글상자 내용도 **자동으로 반영**되어 빠지지 않습니다.

> 📤 **제출 방법:** 저장된 이미지를 학급 플랫폼(구글 클래스룸, 패들렛, 학습지 등)에 올리거나 인쇄해 제출하게 하면 됩니다. 이름이 이미지에 찍혀 있어 **누구 작품인지 한눈에** 구분됩니다. 한 화면에 여러 개의 글상자를 넣어 “변형 과정 + 나의 설명”을 한 장에 담을 수 있습니다.

### 3-6. 전자칠판 모드 — 📽️
버튼을 누르면 **큰 화면 발표·판서에 적합한 모드**로 전환됩니다. 함께 **글자 가+** 로 라벨을 키우면 뒷자리 학생도 잘 볼 수 있습니다. 다시 누르면 일반 모드로 돌아옵니다.

### 3-7. 정리 · 되돌리기
- **↩︎ / ↪︎** — 방금 한 동작을 되돌리거나 다시 실행합니다.
- **🧹 화면 정리** — 옮겨 놓은 패널(도구막대·정보카드·줌·아래 도구모음)을 **기본 위치로 한 번에 복구**합니다. 도형은 그대로 둡니다. *스마트폰·태블릿에서 패널이 엉켰을 때 누르세요.*
- **전체 초기화** — 화면의 모든 도형·메모를 지웁니다. 실수 방지를 위해 **확인 후 실행**됩니다.
- **💾 파일 저장 / 📁 열기** — 작업 전체를 `.json` 파일로 저장했다가 다음 시간에 불러와 **이어서 작업**할 수 있습니다.

## 4. 입체 도형 학습 (3D)

상단 **🧊 입체도형** 버튼으로 이동합니다. (되돌아올 때는 왼쪽 위 **← 평면**)

### 4-1. 다룰 수 있는 입체
**직육면체, 삼각기둥, 오각기둥, 육각기둥, 삼각뿔, 사각뿔, 오각뿔** — 크기(가로·세로·높이)를 조절할 수 있습니다.
오른쪽 카드에서 언제나 **면·모서리·꼭짓점의 수**와 **겉넓이·부피**를 확인할 수 있습니다.

### 4-2. 네 가지 모드

| 버튼 | 모드 | 학습 목표 |
|------|------|-----------|
| 📦 **입체보기** | 손가락/마우스로 **자유롭게 돌려** 보며 면·모서리·꼭짓점을 관찰 | 입체의 구성 요소 |
| 🧊 **쌓기나무** | 위에서 본 칸을 탭해 쌓고(우클릭으로 허물고) **위·앞·옆 세 방향**에서 확인. **부피 = 쌓은 칸 수** | 부피 개념, 여러 방향에서 본 모양 |
| 📄 **전개도** | 입체를 **펼친 전개도**를 보고, 슬라이더로 **상자로 접히는 과정**을 관찰. 접으면 어떤 입체가 될지 예측하는 **전개도 맞추기 퀴즈(11가지)** 포함 | 전개도 ↔ 입체 대응 |
| ✂️ **단면** | 입체를 **수평으로 잘라** 단면 모양과 **단면 넓이**를 확인. “기둥은 어디를 잘라도 단면이 같고, 뿔은 위로 갈수록 작아진다”를 눈으로 확인 | 단면 이해 |

### 4-3. 퀴즈 — ❓
**면·모서리·꼭짓점의 수, 겉넓이, 부피**를 묻는 문제를 무작위로 냅니다. 작은 3D 그림과 함께 나와 형성평가·마무리 활동에 좋습니다.

## 6. 차시별 수업 예시

### 예시 A — 평행사변형의 넓이 (5학년)
1. **📐 도형 추가 → 평행사변형** 불러오기.
2. **넓이·변길이** 켜기, **자석** 켜기.
3. **📚 학습 예시 → 평행사변형 → ‘끝을 잘라 옮기기’** 선택.
4. 아이들이 **✂️ 자르기**로 끝의 직각삼각형을 자르고, **🔗 합치기**로 반대편에 붙여 **직사각형**을 만듭니다.
5. “원래 평행사변형과 넓이가 같다”를 확인 → **넓이 = 밑변 × 높이** 정리.
6. **📝 글상자**에 “왜 넓이가 같은지” 설명을 쓰고 **📷 저장·제출**로 이름을 넣어 제출.

### 예시 B — 삼각형의 넓이 (5학년)
1. **삼각형** 불러오기 → 같은 삼각형을 **`Ctrl+D`로 복제**.
2. 하나를 **회전**해 한 변을 맞붙여 **평행사변형** 만들기(자석 켜기).
3. “삼각형은 평행사변형의 절반” → **밑변 × 높이 ÷ 2** 발견.

### 예시 C — 다각형의 내각의 합 (5학년)
1. **정오각형** 불러오기 → **각도** 켜기.
2. 오른쪽 카드에서 **내각의 합**과 삼각형 분할을 보며 `(변의 수 − 2) × 180°` 유도.
3. **정육각형·정팔각형**으로 바꿔 규칙 확인.

### 예시 D — 직육면체의 겉넓이·부피 (6학년)
1. **🧊 입체도형 → 📦 입체보기**로 직육면체를 돌려 보며 면·모서리·꼭짓점 세기.
2. **🧊 쌓기나무**로 칸을 쌓아 **부피 = 쌓은 칸 수** 확인, **위·앞·옆** 모양 비교.
3. **📄 전개도**로 펼쳐 6개 면을 확인하고 **겉넓이** 계산 → 접기 애니메이션으로 검증.
4. **❓ 퀴즈**로 마무리 형성평가.

## 7. 자주 묻는 질문 · 문제 해결

**Q. 설치가 필요한가요?**
아니요. 웹 브라우저만 있으면 됩니다. **크롬** 최신 버전을 권장합니다. 태블릿·전자칠판·PC 모두 사용할 수 있습니다.

**Q. 도구창이나 넓이창이 화면을 가려요.**
패널 위쪽의 **손잡이(⣿)를 잡아 다른 곳으로 옮기세요.** 화면 비율이 다른 태블릿에서도 겹치지 않게 배치할 수 있습니다.

**Q. 도형이 잘 안 붙어요(합치기 실패).**
**🧲 자석**을 켜고 두 도형의 **한 변이 완전히 맞붙도록** 천천히 가까이 가져가세요. 격자 간격을 **0.5나 1**로 두면 더 잘 붙습니다.

**Q. 글자가 너무 작아 뒷자리에서 안 보여요.**
상단 **글자 가+** 로 4단계까지 키우고, **📽️ 전자칠판** 모드를 함께 사용하세요.

**Q. 아이가 만든 결과물을 어떻게 걷나요?**
**📷 저장·제출**로 만든 PNG 이미지(이름·날짜 + 그림 + 글상자 설명 포함)를 학급 플랫폼에 올리거나 인쇄해 제출하게 하면 됩니다.

**Q. 실수했어요.**
**↩︎ 되돌리기**(`Ctrl+Z`)로 얼마든지 되돌릴 수 있습니다. 새 활동을 시작할 땐 **전체 초기화**로 화면을 비우세요.

**Q. 작업 내용이 저장되나요?**
학습 진도·설정은 브라우저에 자동 저장됩니다. 다만 **결과물(도형·글상자)은 반드시 📷 저장·제출로 이미지로 남겨** 주세요. 브라우저를 닫으면 화면의 도형은 사라질 수 있습니다.
